Drop the two Verdantis logo files in this folder, with these exact names:

  logo-full.png   Full logo (icon + wordmark together) - shown top-left in
                   the site header/topbar, replacing the gradient-box +
                   "Verdantis" text placeholder. Recommended: transparent
                   background PNG, exported tall enough for retina (it's
                   displayed at ~26px tall, so ~80px tall source is plenty).

  logo-small.png   Icon-only mark (no wordmark - it's shown too small to
                   read text). Used as the browser tab favicon and the
                   mobile "add to home screen" icon. Recommended: square,
                   transparent background PNG, at least 512x512px.

Both are picked up automatically once present - no code change needed,
and nothing breaks in the meantime (the current gradient-box brand mark
and default favicon just keep showing).

This copy covers the standalone briefing pages (docs/index.html,
intro-2/3.html, docs/sk/). The per-client dashboard pages need their OWN
copy at docs/_template/assets/img/brand/ (same two filenames) - see the
matching PUT_LOGO_FILES_HERE.txt there - so that each published
docs/c/<slug>/ stays fully self-contained. Add the files to BOTH folders,
then re-run `python publish_site.py --all` to copy them into every
already-published client.
